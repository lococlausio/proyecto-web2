# Mi Proyecto Vue 3 con Vite - Lenguaje WEB 2

Este repositorio contiene la configuración base del entorno de desarrollo frontend utilizando **Vue.js**, **Vite**, **Node.js** y **GitHub**.

## Requisitos
- Node.js LTS
- npm

## Ejecución local
1. Instalar dependencias: `npm install`
2. Iniciar servidor: `npm run dev`
